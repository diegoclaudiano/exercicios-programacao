# Calculadora de Descontos

Exercício prático de lógica de programação para calcular o valor final de uma compra com base em regras de desconto.

## 🎯 Objetivo

Praticar variáveis, operadores e estruturas condicionais (`if`, `else if` e `else`).

## 📋 Regras de desconto

- Até R$ 100,00: sem desconto.
- Acima de R$ 100,00 até R$ 200,00: 10% de desconto.
- Acima de R$ 200,00: 20% de desconto.

## 🛠️ Tecnologias

- HTML5
- JavaScript
